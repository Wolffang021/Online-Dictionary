# Online Web Dictionary

A clean, fast, and lightweight online dictionary web app built using
HTML, CSS, and Vanilla JavaScript.

Search for any English word and instantly get its definition using a public dictionary API - no backend, no nonsense.

🔗 https://wolffang021.github.io/Online-Dictionary

## Features

- Search meanings of English words

- Fast responses with smart caching

- Graceful handling of invalid or unknown words

- Clean, minimal, distraction-free UI

- Fully client-side (powered by GitHub Pages)

- Responsive and usable across screen sizes

## 🚀 How to Use

**Option 1:** Use Online (Recommended)

Just click the live link and start searching.

**Option 2:** Run Locally

Clone or download the repository

Open index.html in your browser

Type a word and hit search

Expand vocabulary 👍
